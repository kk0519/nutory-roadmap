📋 プロジェクト概要

栄養の家計簿 — Meshilog（メシログ）

マネーフォワードが「銀行・クレカ連携で家計を自動管理」したように、
Meshilog は「コンビニ・QR決済・外食チェーン連携で栄養を自動管理」する。
日本のコンビニ文化・キャッシュレス普及を武器に、世界で最も自動化されたカロリー・栄養素トラッカーを目指す。
